# Aurica — Creative Reference Link

Social Content Direction — Vol. 01

Built by Inloop Media

---

A single-page moodboard / social content direction site for **Aurica** — a house of
handcrafted luxury potlis and evening bags. Brand identity (gold monogram, black + gold
theme, Bauer Bodoni typography) taken from the Aurica brand guidelines; content pillars and
reference links supplied by Inloop Media.

- **Display type:** Bodoni Moda (editorial match for Bauer Bodoni) · **Body:** Inter
- **Palette:** near-black `#0f0f0f` ground, gold `#c9aa6a` accent, warm ivory type
- **Pillars:** Founder's Picks · Shop the Edit · Style the Moment · Bag Breakdown · Aurica IRL
- **Grid:** 9 reference pieces (reels, statics + a carousel) with pillar filters and a lightbox gallery
